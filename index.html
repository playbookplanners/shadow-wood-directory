⚙️ One-time setup needed

This app is ready to go, but it needs to be connected to a free Firebase database before it can save data. Open FIREBASE_SETUP.md (included alongside this file) and follow the steps — it takes about 10 minutes. Then paste your config into the firebaseConfig object near the top of this file's <script> section and re-open the page.

Already done this? Then firebaseConfig still has a placeholder value — double-check you saved the file after pasting your keys.
